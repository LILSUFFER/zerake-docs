---
title: PIN-код и Face ID
description: Второй замок на мини-приложении.
---

Мини-приложение просит поставить **6-значный PIN-код**. Он нужен:

- чтобы открыть приложение (если включена блокировка);
- для каждого **снятия фишек** — без верного PIN заявка не создаётся.

Если телефон поддерживает, можно включить **Face ID / отпечаток** через биометрию Telegram — тогда вместо ввода PIN достаточно посмотреть в камеру.

Где: **Настройки** → **PIN и Face ID**.

:::tip
PIN проверяется на сервере. Даже если кто-то откроет ваш Telegram на чужом устройстве, без PIN он не создаст снятие.
:::
