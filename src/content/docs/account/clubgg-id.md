**GG ID** — номер вашего игрового аккаунта, например `3383-3619`. Все фишки клуб выдаёт и снимает именно по этому номеру.

## Где взять

В приложении ClubGG: профиль → номер под никнеймом. В Zerake GG ID показывается и копируется **с дефисом** (`XXXX-XXXX`) — так его удобно вставлять в поиск ClubGG.

## Где указать

Мини-приложение → **Настройки** → поле «GG ID». Без GG ID нельзя создать пополнение или снятие: клубу некуда отправить фишки.

## Один GG ID — один аккаунт

Один GG ID можно привязать **только к одному** аккаунту Zerake. Это защищает от схемы, когда кто-то вписывает чужой GG ID (например, увиденный на стриме) и пытается получить на него операции или снять с него фишки.

Если GG ID уже привязан к другому Telegram — значит, вы раньше играли с другого аккаунта. Восстановите его [секретной фразой](/account/recovery/), а не создавайте новый.

:::caution
Проверьте GG ID перед первым пополнением. Фишки уходят на тот номер, который указан в настройках.
:::
