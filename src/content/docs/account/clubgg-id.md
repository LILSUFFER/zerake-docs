**ID в ClubGG** — номер вашего игрового аккаунта, например `3383-3619`. Все фишки клуб выдаёт и снимает именно по этому номеру.

## Где взять

В приложении ClubGG: профиль → номер под никнеймом. В Zerake ID показывается и копируется **с дефисом** (`XXXX-XXXX`) — так его удобно вставлять в поиск ClubGG.

## Где указать

Мини-приложение → **Настройки** → поле «ID в ClubGG». Без ID нельзя создать пополнение или снятие: клубу некуда отправить фишки.

## Один ID — один аккаунт

Один ID в ClubGG можно привязать **только к одному** аккаунту Zerake. Это защищает от схемы, когда кто-то вписывает чужой ID (например, увиденный на стриме) и пытается получить на него операции или снять с него фишки.

Если ID уже привязан к другому Telegram — значит, вы раньше играли с другого аккаунта. Восстановите его [секретной фразой](/account/recovery/), а не создавайте новый.

:::caution
Проверьте ID перед первым пополнением. Фишки уходят на тот номер, который указан в настройках.
:::
