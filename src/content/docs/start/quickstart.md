## 1. Откройте бота

Перейдите в [@zerakebot](https://t.me/zerakebot) и нажмите **Start**. Бот покажет кнопки «Купить фишки», «Продать фишки» и «История». Любая из них открывает мини-приложение Zerake.

## 2. Укажите ID в ClubGG

Откройте в мини-приложении **Настройки** (значок шестерёнки) и введите ваш ID из ClubGG. Он выглядит так: `3383-3619`. Именно на этот ID придут фишки. Подробнее — [ID в ClubGG](/account/clubgg-id/).

Вступите в клуб в ClubGG по ID клуба **976434**, если ещё не вступили.

## 3. Сохраните секретную фразу и поставьте PIN

При первом входе приложение покажет **секретную фразу из 12 слов**. Запишите её на бумагу — без неё нельзя сменить кошелёк или восстановить аккаунт. Затем поставьте **6-значный PIN** и, если хотите, Face ID. Подробнее — [Секретная фраза](/account/secret-phrase/), [PIN-код](/account/pin/).

## 4. Привяжите кошелёк и пополните

На вкладке **Купить** выберите сеть и привяжите **свой личный кошелёк** в этой сети — на него будут приходить выплаты. Потом пополните:

- **TRC20 / BEP20** — введите сумму, приложение покажет точную сумму и адрес, отправьте ровно её. [Подробнее](/money/deposit-request/)
- **TON / GRAM** — за вами закрепят персональный адрес клуба, отправляйте на него любую сумму в любое время. [Подробнее](/money/deposit-personal/)

## 5. Играйте

Когда платёж найдётся (обычно в течение минуты), приложение покажет «Платёж получен», а затем «Фишки зачислены». Фишки уже на вашем ID в ClubGG — садитесь за стол.

:::tip[Снять фишки]
Вкладка **Продать** → сеть → сумма → PIN. Деньги придут на привязанный кошелёк. Подробнее — [Снятие фишек](/money/withdrawal/).
:::
