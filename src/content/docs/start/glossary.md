---
title: Словарь
description: Термины, которые встречаются в документации и приложении.
---

| Термин | Значение |
|---|---|
| **ClubGG** | Приложение, в котором проходит игра. Клуб Zerake — внутри него. |
| **ID в ClubGG** | Ваш номер игрока в ClubGG, вида `3383-3619`. На него приходят фишки. |
| **Фишки** | Игровой баланс в клубе. 1 фишка = 1 USDT. |
| **Рейк** | Процент, который клубы обычно берут с каждого банка. В Zerake его нет. |
| **Пополнение фишек** | Перевод криптовалюты клубу → фишки на ваш ID. Номер операции начинается с `DEP-`. |
| **Снятие фишек** | Фишки снимаются с вашего ID → криптовалюта на ваш кошелёк. Номер операции начинается с `WD-`. |
| **USDT** | Стейблкоин, 1 USDT ≈ 1 доллар. |
| **TRC20 / BEP20 / TON** | Сети, в которых ходит USDT: Tron, BNB Chain и TON. |
| **GRAM** | Монета сети TON (бывший Toncoin). Её курс меняется, фишки считаются по курсу в момент поступления. |
| **Привязанный кошелёк** | Ваш личный кошелёк в сети, на который клуб отправляет выплаты. Один на сеть. |
| **Секретная фраза** | 12 слов, которые подтверждают, что аккаунт ваш. Нужны для смены кошелька и восстановления. |
| **Заявка на пополнение** | Для TRC20 и BEP20: точная сумма и адрес на 30 минут. |
| **Персональный адрес** | Для TON и GRAM: адрес клуба, навсегда закреплённый за вами, без суммы и срока. |
| **Агент** | Программа клуба, которая выдаёт фишки в ClubGG автоматически. |
| **Админка** | Сайт для команды клуба: очереди, операции, поддержка. |
