## Принцип: без лишних переводов

Деньги остаются **там, куда пришли**, пока не понадобится выплата. Клуб не «собирает» их по расписанию на один кошелёк: каждый лишний перевод стоит газа и создаёт лишнюю точку отказа.

| Сеть | Куда приходят пополнения | Откуда идут выплаты |
|---|---|---|
| TRC20 | пул адресов клуба (GasFree-адреса) | напрямую с этих адресов |
| BEP20 | пул адресов клуба | напрямую с этих адресов, газ — с отдельного адреса клуба |
| TON (USDT) | личные адреса игроков + кошелёк клуба | напрямую с них, газ докидывает кошелёк клуба |
| GRAM | личные адреса игроков + кошелёк клуба | напрямую, при необходимости части объединяются |

## Ключи

Все адреса клуба выводятся из **ключей клуба** по номеру (иерархические кошельки). Ключи хранятся только в защищённых настройках сервера. Отдельного «горячего кошелька для выплат» нет.

## Контроль платёжеспособности

В админке команда видит по каждой сети:

- сколько лежит на всех адресах;
- сколько уже обещано к выплате;
- сколько свободно;
- хватает ли на комиссии.

Если обещано больше, чем лежит, админка подсвечивает это красным, а новые снятия в этой сети не принимаются. См. [Проверка платёжеспособности](/cash-out/solvency/).
