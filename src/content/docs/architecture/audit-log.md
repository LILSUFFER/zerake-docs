---
title: Журнал операций
description: Неизменяемая история каждого пополнения и снятия.
---

Каждое изменение пополнения или снятия **база данных сама** записывает в журнал:

| Поле | Что хранится |
|---|---|
| Номер операции | `DEP-…` / `WD-…` |
| Событие | создана, взята в работу, отпущена, смена статуса (`было → стало`), проверка агента |
| Кто | человек из команды, агент или система |
| Сумма | на момент события |
| Полная запись | вся строка операции после изменения |
| Что изменилось | старые значения изменённых полей |
| Когда | время с точностью до секунды |

Журнал **только дописывается**: изменить или удалить запись нельзя ни из приложения, ни из админки. По нему можно восстановить, кто, когда и что сделал с любой операцией.

В админке журнал ищется по номеру операции или ID в ClubGG.
