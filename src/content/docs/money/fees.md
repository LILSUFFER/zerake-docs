## Пополнение

| Сеть | Комиссия клуба | Комиссия сети |
|---|---|---|
| TRC20 | 0 | платит **отправитель** (с биржи обычно несколько долларов) |
| BEP20 | 0 | платит отправитель (центы) |
| TON (USDT) | 0 | платит отправитель (доли цента в GRAM) |
| GRAM | 0 | платит отправитель (доли цента) |

Сумма, отправленная вами, должна **дойти целиком**. Если биржа вычитает свою комиссию из суммы перевода — увеличьте сумму.

## Снятие

| Сеть | Комиссия при снятии | Снимаете 100 фишек — получите |
|---|---|---|
| **TRC20** | **3 USDT + 1%** | 96 USDT |
| BEP20 | 0 | 100 USDT |
| TON (USDT) | 0 | 100 USDT |
| GRAM | 0 | GRAM на 100 USDT по курсу |

**Почему в TRC20 есть комиссия.** Перевод USDT в Tron дорогой — за него сжигается TRX. Выплаты идут через сервис **GasFree**, который берёт плату в USDT; эта плата и есть комиссия снятия. В остальных сетях газ стоит доли цента — его платит клуб.

**Рейка нет.** Со столов клуб ничего не берёт.
