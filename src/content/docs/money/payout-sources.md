## Правило выбора

1. Сервер смотрит баланс **каждого адреса клуба** в сети.
2. У каждого адреса оставляется запас на его собственный газ.
3. Есть **один адрес, где хватает** на всю выплату, — платит с **самого маленького** из таких: крупные остаются для крупных выплат.
4. Ни на одном не хватает — сумма набирается с нескольких адресов, **начиная с самых крупных**.

## Газ

| Сеть | Кто платит | Как |
|---|---|---|
| TRC20 | игрок, в комиссии снятия | сервис GasFree берёт плату в USDT прямо с адреса — TRX не нужен |
| BEP20 | клуб | адрес для комиссий докидывает BNB на платящий адрес |
| TON (USDT) | клуб | кошелёк клуба докидывает ~0.07 GRAM на платящий адрес |
| GRAM | клуб | из запаса на самом адресе |

## Один перевод в TON и GRAM

1. Если сумму приходится собирать с нескольких адресов, части сначала **переводятся на один адрес клуба**.
2. Каждая часть идёт **с запасом 0.01 GRAM на газ** — приём перевода тоже стоит газа.
3. Сервер ждёт, пока объединённая сумма поступит (до 90 секунд).
4. Только потом уходит **один перевод игроку**.
5. Если объединение не завершилось — игроку **ничего не отправляется**, заявка возвращается команде.
