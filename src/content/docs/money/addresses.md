---
title: Адреса клуба
description: Какие адреса бывают, кто владеет ключами и как живёт общий адрес.
---

**Все адреса — адреса клуба.** Ключи от них есть только у клуба. Разница только в том, как определяется, чей платёж.

| Адрес | Сеть | Чей платёж | Сколько их |
|---|---|---|---|
| **Общий адрес** | TRC20 (GasFree-адрес) | по уникальной сумме заявки | несколько, по очереди |
| **Общий адрес** | BEP20 | по уникальной сумме заявки | несколько, по очереди |
| **Персональный адрес** | TON (USDT и GRAM) | по самому адресу — он закреплён за одним игроком | по одному на игрока |
| **Адрес для комиссий** | BEP20 | — | один, докидывает BNB на газ |
| **Кошелёк клуба** | TON | — | один, платит газ за выплаты USDT в TON |

## Ключи

1. Все адреса выводятся из **ключей клуба** по порядковому номеру (иерархические кошельки).
2. Ключи лежат **только в защищённых настройках сервера** — не в коде, не в базе, не в приложении, не у команды.
3. Сервер, который **выдаёт адреса** для заявок, знает только **публичный ключ**: посчитать новый адрес может, отправить с него деньги — нет.
4. Отправлять деньги может только **сервер выплат**, и только после всех проверок.

## Жизненный цикл общего адреса

![Жизненный цикл общего адреса](/diagrams/pool-address.svg?v=ce44ad9f)

1. Для новой заявки берётся **первый открытый** адрес сети.
2. Нет открытых — сервер **создаёт следующий** по номеру.
3. Адрес принимает пополнения многих игроков, пока поступления на нём не достигнут **порога** (по умолчанию 5 000 USDT).
4. После этого он **«заполнен»** и в новых заявках не выдаётся.
5. Деньги с него **никуда не перекладываются** — с него платятся выплаты.

## Персональный адрес

1. Создаётся при первом открытии вкладки TON или GRAM и **навсегда закрепляется** за игроком.
2. Это отдельный кошелёк клуба, выведенный из ключа клуба по номеру игрока.
3. Деньги лежат на нём, пока не понадобятся для выплаты.
