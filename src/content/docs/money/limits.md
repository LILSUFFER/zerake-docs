description: Все ограничения, которые стоят на пути денег, в одном месте.

| Проверка | Когда | Зачем |
|---|---|---|
| Минимум пополнения | создание заявки / поступление на личный адрес | отсечь копеечные переводы |
| Максимум пополнения по заявке — 50 000 USDT | создание заявки | контроль крупных сумм |
| Срок заявки — 30 минут | TRC20/BEP20 | не держать «хвосты» занятыми вечно |
| Кошелёк для выплат привязан | пополнение и снятие | выплата только владельцу |
| PIN | снятие | второй замок |
| Нет смены кошелька, прошло 48 ч после восстановления | снятие | защита от угона аккаунта |
| Одна открытая заявка на снятие | снятие | порядок в очереди |
| Хватает средств клуба в сети | создание снятия **и** перед снятием фишек | не снять фишки, которые нечем выплатить |
| Снятая сумма совпадает с заявкой до цента | менеджер нажимает «Фишки сняты» | защита от ошибки ввода |
| Лимит автовыплаты за раз и в сутки | выплата | крупные суммы платит человек |
| Блокировка заявки перед выплатой | выплата | одна заявка — одна выплата |
| Уникальность «сеть + хэш» | поступление | один перевод — одно зачисление |
