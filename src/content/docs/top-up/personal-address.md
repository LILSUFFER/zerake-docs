В сети **TON** (и для USDT, и для монеты GRAM) у вас есть **личный адрес** — он принадлежит клубу, но закреплён только за вами.

## Шаги

1. Вкладка **Купить** → **TON** (USDT) или **GRAM**.
2. Скопируйте адрес или отсканируйте QR.
3. Отправьте **любую сумму** от минимума. Без комментария, без мемо, без точной суммы, без срока.

Платёж определяется по адресу, поэтому перепутать его с чужим невозможно.

## GRAM: курс

GRAM — монета с плавающим курсом. Фишки начисляются **по курсу в момент поступления** (берётся с бирж Binance / OKX / CoinGecko). На экране видно примерный курс и минимум в GRAM.

Для GRAM есть допуск **3%** на движение курса: если из-за курса сумма оказалась чуть меньше минимума, она всё равно зачислится.

:::caution[Только своей сети]
На адрес TON отправляйте **только USDT в сети TON** (вкладка TON) или **только GRAM** (вкладка GRAM). Другие монеты на этот адрес будут потеряны.
:::

:::tip[Комиссия]
Комиссию сети платит отправитель — это доли цента. Держите на кошельке немного GRAM для комиссии.
:::

## Где хранятся деньги

Деньги остаются на вашем личном адресе, пока клубу не понадобится сделать выплату — тогда они уходят напрямую получателю. Подробнее — [Хранение средств](/architecture/funds/).
