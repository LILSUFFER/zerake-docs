Адрес: **zerake.com/admin**. Вход — через Telegram, только для людей из списка команды.

| Раздел | Для чего | Кто видит |
|---|---|---|
| **Очередь** | Пополнения и снятия, ждущие действий | все |
| **Все операции** | Поиск, фильтр по статусу, смена статуса вручную | владелец |
| **Неопознанные** | Платежи, не совпавшие ни с одной заявкой | все |
| **Журнал** | История изменений операций | все |
| **Агент** | Связь с агентом, что выдал, где ошибся; включить/выключить | владелец |
| **Команда и кошелёк** | Менеджеры; сколько можем выплатить в каждой сети | владелец |

Очередь обновляется каждые 8 секунд. Новая заявка — звуковой сигнал и число в заголовке вкладки.

:::caution[Смена статуса вручную]
В «Все операции» можно поставить любой статус. Это меняет **только запись**: фишки и деньги никуда не отправляются. Используйте, чтобы исправить запись после ручной работы. Каждое изменение попадает в журнал.
:::
