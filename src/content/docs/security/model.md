## Деньги игроков

| Угроза | Защита |
|---|---|
| Кто-то зашёл в ваш Telegram | Выплаты только на привязанный кошелёк; снятие требует PIN |
| Кто-то хочет сменить кошелёк | Только секретной фразой, через 48 ч, с уведомлением и отменой |
| Поддержку уговорили «сменить кошелёк» | У поддержки нет такой функции — физически |
| Чужой ID в ClubGG | Один ID — один аккаунт |
| Двойная выплата | Каждая заявка блокируется при выплате, повтор невозможен |
| Снятие, которое нечем выплатить | [Проверка платёжеспособности](/money/withdrawal/) до снятия фишек |
| Ошибка менеджера в сумме | Менеджер вводит снятую сумму — она должна совпасть с заявкой до цента |

## Сервер

- Все решения о деньгах принимает **сервер**. Приложение только показывает кнопки.
- Доступ к данным разделён правилами на уровне базы: игрок видит только свои операции.
- Ключи кошельков хранятся только в защищённых настройках сервера, не в коде и не в базе.
- Все изменения операций пишутся в [журнал](/architecture/audit-log/), который нельзя изменить или удалить.

## Команда

- Доступ к админке — только у людей из списка команды, вход через Telegram.
- У каждой заявки виден исполнитель: кто взял, кто выдал, кто выплатил.
